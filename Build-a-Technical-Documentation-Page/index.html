Create a table

A table stores records in rows. In this example, each row represents one book, and each column describes something about it.

CREATE TABLE books (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    genre TEXT NOT NULL,
    pages INTEGER NOT NULL
);

Run these examples in order in a fresh SQLite database. The first statement creates the table that the other examples use.

  • id identifies one book.
  • title holds the name printed on the cover.
  • genre groups similar books.
  • pages holds a whole-number page count.

Insert rows

INSERT INTO adds records. List the columns first, then supply the values for each row in the same order.

INSERT INTO books (title, genre, pages)
VALUES
    ('Night Train', 'Mystery', 210),
    ('Glass Garden', 'Fantasy', 320),
    ('Last Stop', 'Mystery', 185);

SQLite fills in the integer primary key when you omit it. After this statement, the table contains three books.

Select columns

SELECT chooses the columns to show in the result. FROM names the table to read.

SELECT title, pages
FROM books;

This query displays the title and page count for all three books. The stored rows keep all four columns.

Filter rows

WHERE keeps the rows that satisfy a condition. Put text values inside single quotes.

SELECT title
FROM books
WHERE genre = 'Mystery';

The example returns Night Train and Last Stop. Add another condition with AND when both conditions must hold.

Sort results

ORDER BY arranges the returned rows. DESC puts the largest page count first, so Glass Garden appears at the top.

SELECT title, pages
FROM books
ORDER BY pages DESC, id ASC
LIMIT 2;

LIMIT keeps only the first two rows after sorting. The second sort column makes the order predictable when page counts match.

  • Use ASC for ascending order.
  • Use DESC for descending order.

Count by genre

GROUP BY collects rows with the same genre into a group. COUNT(*) counts the rows in each group.

SELECT genre, COUNT(*) AS book_count
FROM books
GROUP BY genre
ORDER BY genre;

The result has two rows. Fantasy has one book and Mystery has two. The alias book_count gives the result column a readable name.
