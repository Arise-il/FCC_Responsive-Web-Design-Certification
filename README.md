# freeCodeCamp Responsive Web Design Certification

**[View my certificate on freeCodeCamp](https://www.freecodecamp.org/certification/ilyas-elghoulti/responsive-web-design-v9)**

This repository brings together the five HTML and CSS projects I built for freeCodeCamp’s Responsive Web Design Certification.

## Certification projects

### Survey Form · Listening Room

Listening Room is a music survey where visitors share their favorite genres and recommend a record. I used radio buttons for questions with one answer, checkboxes for questions with several answers, and a text area for recommendations.

### Page of Playing Cards

I built a four-card layout on a green felt background. I used CSS Flexbox to arrange the cards on the table and to position the corner markings and center symbol inside each card.

### Book Inventory App

This inventory displays five books with their authors, categories, reading statuses, and ratings. I used CSS attribute selectors to style each row by reading status and filled dots to show each book’s rating at a glance.

### Technical Documentation Page · SQL Field Guide

SQL Field Guide is a six-section reference that walks readers through creating and querying a small book database. Readers can jump directly to a topic using a fixed sidebar on desktop, and the navigation adapts to smaller screens.

### Product Landing Page · Short Reel

Short Reel is a landing page for a film club. Visitors can watch an embedded preview of *Big Buck Bunny*, use the navigation to explore the page, and enter their email in the signup form.
